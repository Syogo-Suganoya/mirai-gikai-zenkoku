# 都道府県議会の調査（会議録・議案・議決結果の公開状況）

- 調査日: 2026-10-10
- 目的: 地方版みらい議会で「議案書・議事録の一覧ページを登録して自動で取り込む」方式（設計メモ 2.4節）が、47都道府県議会でどこまで通用するかを確かめる
- 方法: 各議会の公式サイトのトップページを開き、会議録・議案・議決結果へのリンクを拾った。トップから辿れないものは検索で補った
- 関連: [地方版みらい議会設計.md](地方版みらい議会設計.md)（とくに 6.3・6.4 節）

## 1. わかったこと（要点）

1. **会議録は4種類のシステムで41議会をカバーしている。** 自治体ごとではなく、システムごとに読み取りを作れば大半に対応できる（設計メモ 6.4 の「業者ごとの読み取りは作ってよい」を裏づける）
2. **会議録の公開は遅い。** 徳島県議会は「定例会終了後おおむね3か月後に掲載」と明記している。高知県議会も「最新の会議録は検索システムに載っていない場合がある（PDF版のみ）」としている。審議の進み具合の元には使えない（設計メモ 6.3 を裏づける）
3. **速報版を別に出す議会がある。** 北海道・秋田・千葉・青森・福井・佐賀などは、正式な会議録の前に「速報版」をHTML・PDFで出している。取り込み元にするなら速報版のページのほうが早い
4. **議案・議決結果のページは置き場所がばらばら。** トップから直接辿れたのは約半数。定例会ごとのページの中にあるもの、県庁側（財政課など）のページにあるもの（長崎・福井・高知・徳島）がある。URL登録画面では、議会サイト以外のページも登録できる必要がある
5. **議決結果は比較的見つけやすい。** 「議案等の審議結果」「提出議案と議決結果」といった定例会ごとの一覧を持つ議会が多い。設計メモ 6.3 の「議決結果の一覧ページを主な取り込み元にする」は現実的
6. **VOICES形式（gijiroku.com 系）のシステムは、会議録だけでなく議案・議決結果・会期日程のページも持っている**（岩手・滋賀で確認）。このシステムの議会は自動化しやすい

## 4. 設計への示唆

| 設計メモの論点 | 調査からの示唆 |
|---|---|
| 2.4 一覧URLの登録 | 議案のページは、議会サイトの「定例会ごとのページ」の中にあることが多い。登録するのは「議案の一覧ページ」ではなく **「定例会の一覧ページ」** にし、そこから会期ごとのページを辿る必要がある |
| 2.4 一覧URLの登録 | 議案書を **県庁側（財政課など）が公開している** 議会がある（長崎・福井・高知・徳島）。議会サイト以外のURLも登録できるようにする |
| 6.3 議事録は遅すぎる | 徳島は約3か月後に掲載と明記。審議の進み具合の元には **議決結果の一覧ページ** を使う。議事録を使う場合も、正式版より先に出る **速報版** のページを取り込み元にする |
| 6.4 業者ごとの読み取り | Discuss・dbsr・VOICES形式・kensakusystem の **4種類で41議会**。この4種類に対応すれば、都道府県議会の会議録はほぼ取れる。残りの6議会は独自（岩手・東京・山梨・静岡）か、自サイトのPDF・HTML（長野・和歌山） |
| 6.4 業者ごとの読み取り | VOICES形式は議案・議決結果・会期日程のページも持っているので、このシステムの議会（北海道・栃木・群馬・千葉・石川・滋賀・岩手の一部）は議案側まで自動化しやすい |
| 6.2 参考資料・例規集 | 今回は調べていない。次の調査で、例規集の公開システムと、新旧対照表が議案書に含まれるかを確認する |

## 5. 調査の限界と次の作業

- 公式サイトのURLは、大阪府議会のリンク集（掲載が古い可能性あり）と実際の取得結果を突き合わせたもの。リダイレクトやURLの変更があった議会（秋田・群馬・新潟・奈良・沖縄など）は取得できたURLに直した
- 議案・議決結果は **トップページから辿れたものだけ** を記載した。空欄の議会にも、定例会ごとのページの中にある可能性が高い
- 提供会社は、ページ内に記載があった Discuss（NTTアドバンステクノロジ）以外は確定していない
- 長野県議会のサイトは自動取得で403が返った。取り込み元にする場合は、取得方法（間隔・User-Agent）の配慮が必要

次にやること（案）:

1. 空欄の議会について、定例会ごとのページを開き、議案書PDF・議決結果の置き場所を確認する
2. 例規集のシステム（提供会社）と、新旧対照表の有無を調べる（設計メモ 6.2）
3. 試験運用の候補（チームみらいの地方議員がいる議会）が決まったら、その議会について1会期分の議案書・議決結果・会議録が実際に取れるかを試す
