条例 委員会で審査中

市立小中学校の給食費を無償にする条例

正式名称: あおば市学校給食費の保護者負担の軽減に関する条例の制定について

ひとことで言うと ふつうくわしく
来年4月から、市立の小中学校に通う子ども（約9,800人）の給食費を、市が全額負担します。保護者の負担は1人あたり年間 およそ5万円減ります。市の負担は年間およそ12億円で、ふるさと納税の基金などから出します。
どう変わる？
いま 来年4月から
小学生 月4,300円 0円
中学生 月5,100円 0円

  • 9月10日〜 文教委員会で審査中
  • 9月26日 本会議で採決（予定）

賛成（あおば市議会議員 ○○ ○○）
子育て世帯の負担軽減として効果が大きい。ただし財源の基金が5年で尽きる見込みのため、継続のための財源計画を委員会で質問します。
