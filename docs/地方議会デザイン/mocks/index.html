地方版みらい議会 画面モック

設計メモ 地方議会デザイン/地方版みらい議会設計.md の画面イメージ。静的HTMLで、ボタンやリンクは画面遷移のイメージのみ。 議会名・議案はすべて架空です。

📘 使い方ガイド（フローチャート付き）

住民・担当者・運営それぞれの操作の流れを、画面へのリンク付きで説明

公開サイト（web）

議会選択画面

都道府県 → 議会を選ぶ。議案が公開済みの議会だけ選べる

議会トップ画面

開会中の定例会と議案一覧、過去の定例会

議案詳細画面

概要（ふつう／くわしく）、審議の進み具合、AIチャット、インタビュー

議案未掲載画面

空のページは出さず、公開の通知の登録を呼びかける

管理画面（admin）

議会一覧画面（全体管理者）

議会の追加・公開設定・担当者の状況

ダッシュボード画面

担当議会の定例会と議案、確認待ちの件数

アップロード画面

議案書PDFをアップロード → AIが議案ごとに分割・下書き

下書き確認画面

原文PDFと下書きを並べて確認・修正 → 公開

URL登録画面

議案書・議事録の一覧ページを登録し、新しいものを自動で取り込む

担当者管理画面

議会ごとの編集者・確認者を招待する
